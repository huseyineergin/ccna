# 1.8 LAN Architectures
## Introduction
A **star topology** is a network layout in which **every device is connected to a single central device**, such as a switch or hub. All communication between connected devices passes through that central device.

A **full mesh topology** is a network layout in which **every device is directly connected to every other device** in the network.

A **partial mesh topology** is a network layout in which **some devices are directly connected to multiple other devices, but not every device is connected to every other device**.
## Two-Tier LAN Design
A two-tier LAN design is a network architecture that combines the traditional three-layer network model into two layers: the **access layer** and the **distribution layer**.
- It is also called a **collapsed core design** because it combines the core and distribution layers of the traditional three-tier LAN design into a single layer.
- The access layer connects end hosts to the network.
	- Access layer switches typically have many ports for connecting end hosts.
	- QoS marking is usually performed at this layer.
	- Security features such as port security and DAI are typically implemented at this layer.
	- Switch ports may support PoE to power devices such as wireless APs and IP phones.
- The distribution layer aggregates access switches and controls traffic between network segments.
	- It is sometimes called **aggregation layer**.
	- Typically serves as the **boundary between Layer 2 and Layer 3**.
	- Connects to external services such as the Internet and WAN.
- Connections between distribution switches operate at Layer 3. Routing information can be exchanged using protocols such as OSPF.
- In large LANs with many distribution layer switches (e.g., in separate buildings), the number of required connections between distribution layer switches increases rapidly.
	- A **core layer** can be added to improve the scalability of large LANs.
	- Cisco recommends adding a core layer when **more than three distribution layers** are deployed at a single location.

## Three-Tier LAN Design
A three-tier LAN design is a hierarchical network architecture that divides a network into three layers: **access**, **distribution** and **core**.
- The core layer connects distribution layers in large LANs.
	- The focus of this layer is **speed**.
	- CPU-intensive operations, such as security checks and QoS marking/classification, should be avoided at this layer.
	- All connections operate at Layer 3, eliminating the need for STP.
	- Because it’s the backbone of the LAN, redundancy of devices and connections is essential.

## Spine-Leaf Architecture
Spine-leaf architecture is a network topology commonly used in modern data centers. It connects servers through two layers of network switches, **leaf switches** and **spine switches**, to provide low latency, high bandwidth and scalability.
- Data centers are dedicated spaces that house computer systems, such as servers and network devices.
- Traditional data center designs used a three-tier architecture.
	- This worked well when most data center traffic flowed in a **north–south** direction.
- With the precedence of virtual servers, applications are often deployed across multiple physical servers, increasing the amount of **east–west** traffic in the data center.
	- The traditional three-tier architecture led to bandwidth bottlenecks and variations in server-to-server latency, depending on the path taken by the traffic.
	- To solve these issues, spine-leaf architecture, also known as **Clos architecture**, has become widely used in data centers.
- There are some rules in spine-leaf architecture:
	- Every leaf switch is connected to every spine switch.
	- Leaf switches do not connect to other leaf switches.
	- Spine switches do not connect to other spine switches.
	- End hosts are only connected to leaf switches.
- The path taken by traffic is randomly chosen to balance the load among the spine switches.
- Each server is separated by the same number of **hops**, except for servers connected to the same leaf switch, providing consistent latency for east–west traffic.

## SOHO (Small Office/Home Office) Networks
A SOHO network is a computer network designed for a small business, a home office or a household to connect multiple devices and share resources.
- SOHO networks don’t have complex needs, so all networking functions are provided by a single device, often called a home router or wireless router.
- This single device can function as a router, switch, firewall, wireless access point and modem.
