# 1.4 Ethernet LAN Switching
## Introduction
### OSI Model - Physical Layer (L1)
- Defines physical characteristics of the medium used to transfer data between devices such as voltage levels, maximum transmission distances, physical connectors and cable specifications.
- Digitals bits are converted into **electrical (for wired connections) or radio (for wireless connections) signals**.
### OSI Model - Data Link Layer (L2)
- Provides **node-to-node connectivity** and data transfer such as PC to switch, switch to router and router to router.
- Defines how data is formatted for transmission over a physical medium.
- Detects and possibly corrects Physical Layer errors.
## Ethernet Frame Structure
- The minimum size for an Ethernet frame (Header + Payload + Trailer) is **64 bytes**.
- 64 bytes - 18 bytes (Header + Trailer) = 46 bytes, therefore minimum payload size is **46 bytes**.
- If payload is less than 46 bytes, padding bytes of all 0's are added.

### Preamble
Ethernet frame starts with a **7-bytes** preamble. The preamble bit values alternate 1 and 0, allowing receivers to synchronize their clock at the bit-level with the transmitter.
### SFD (Start Frame Delimiter)
SFD is a **1-byte** field that is always set to **10101011**. It indicates that upcoming bits are starting the frame, which is the destination address.
### Destination and Source Addresses
The Destination and Source Addresses are **both 6-byte MAC addresses**. The Destination Address identifies the device that should receive the frame, while the Source Address identifies the device that sent the frame. They are used by switches to make forwarding decisions.
#### MAC Address
A MAC address is a **unique identifier** assigned to a **network interface controller (NIC)** for communication on a local network.
- **6 bytes** long physical address assigned to the device when it is made by device manufacturers.
- Often referred to as the burned-in address.
- The **first 3 bytes** are the manufacturer's **organizationally unique identifier (OUI)**, which is assigned to the company making the device.
- The last **3 bytes** are unique to the device itself.
- It is written as **12 hexadecimal** characters.
### EtherType
The EtherType field is **2 bytes** long and it can be used for two different purposes. It can be used to represent either the **type of the encapsulated packet**, or the **length of the encapsulated packet**.
- A value of **1500 or less** indicates the length of the encapsulated packet in bytes.
- A value of **1536 or greater** indicates the type of the encapsulated packet, typically IPv4 or IPv6, and the length of the frame is determined using other methods.
	- IPv4 = 0x0800, 2048 in decimal.
	- IPv6 = 0x86DD, 34525 in decimal.
	- ARP = 0x0806, 2054 in decimal.
### FCS (Frame Check Sequence)
FCS is a **4-bytes cyclic redundancy check (CRC )** that allows **detection of corrupted data** within the entire frame that occurred during transmission.
#### CRC (Cyclic Redundancy Check)
CRC is an **error-detecting code** commonly used in digital networks and storage devices to detect accidental changes to digital data. It contains a 4-bytes hash code of data, which is **generated over the destination address, source address, EtherType, and data field**.
