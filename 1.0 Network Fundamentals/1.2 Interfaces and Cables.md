# 1.2 Interfaces and Cables
## Introduction
**Ethernet** is a collection of network protocols/standards.

Speed is measured in **bits per second (e.g., Kbps, Mbps, Gbps)**, not bytes per second.
## Duplex Communications
### Full-Duplex Transmission
A communication method in which data can be **sent and received simultaneously in both directions**.
- Both devices can transmit and receive at the same time.
- No collisions occur because each direction has a separate communication path.
- Example: A phone call.
### Half-Duplex Transmission
A communication method in which data can be **sent and received in both directions, but not simultaneously**.
- Both devices can transmit and receive, but they must **take turns**.
- Collisions can occur because both devices share the same communication path and cannot transmit simultaneously.
- Example: Walkie-talkie communication.
### Simplex Transmission
A communication method in which data can be **sent in only one direction**.
- The sender can transmit data, but the receiver cannot send data back.
- Communication is **one-way only**.
- Example: TV broadcasting.
## Ethernet (Copper)
### Standards
|  Speed   |     Common Name     | IEEE Standard | Informal Name | Cables  | Maximum Length |
| :------: | :-----------------: | :-----------: | :-----------: | :-----: | :------------: |
| 10 Mbps  |      Ethernet       |    802.3i     |   10BASE-T    | 2 Pairs |      100m      |
| 100 Mbps |    Fast Ethernet    |    802.3u     |  100BASE-TX   | 2 Pairs |      100m      |
|  1 Gbps  |  Gigabit Ethernet   |    802.3ab    |  1000BASE-T   | 4 Pairs |      100m      |
| 10 Gbps  | 10 Gigabit Ethernet |    802.3an    |   10GBASE-T   | 4 Pairs |      100m      |
>T = Twisted Pair, BASE = Baseband Signaling
### Twisted-Pair Cables
Twisted-Pair Cable is a type of copper Ethernet cable made of pairs of insulated copper wires twisted around each other. The twisting helps **reduce electromagnetic interference (EMI) and crosstalk** between adjacent wire pairs.
- Transmit (Tx) pins send data.
- Receive (Rx) pins receive data.
- 10BASE-T and 100BASE-T use 2 pairs (4 wires). One pair for Tx and one pair for Rx.
	- Pins 1,2 → Tx on MDI / Rx on MDI-X
	- Pins 3,6 → Rx on MDI / Tx on MDI-X
	- Pins 4,5 → Unused
	- Pins 7,8 → Unused
- 1000BASE-T and 10GBASE-T use all 4 pairs (8 wires) for simultaneous Tx/Rx.

| Device Type | Transmit (Tx) Pins | Receive (Rx) Pins |
| :---------: | :----------------: | :---------------: |
|   Router    |        1,2         |        3,6        |
|  Firewall   |        1,2         |        3,6        |
|  PC/Server  |        1,2         |        3,6        |
|   Switch    |        3,6         |        1,2        |
#### UTP (Unshielded Twisted-Pair) Cables
UTP cable is a twisted-pair cable that has no metallic shielding around the individual pairs or the cable as a whole.
- Each pair consists of two insulated copper wires twisted together.
- The twisting helps reduce EMI and crosstalk between pairs.
- UTP cables are lightweight, flexible, and generally less expensive than shielded twisted-pair (STP) cables.
- Commonly used in Ethernet networks, especially in offices, homes and data centers.
#### STP (Shielded Twisted-Pair) Cables
STP cable is a twisted-pair cable that uses metallic shielding to provide additional protection against EMI and crosstalk.
- Shielding can be applied around individual pairs, around groups of pairs, or around the entire cable.
- Provides better protection against external electrical interference than UTP cables.
- Generally more expensive, thicker, and less flexible than UTP cables.
- Useful in environments with significant electromagnetic interference, such as industrial facilities.
### Cabling and Pinouts
#### Straight-Through Cable
A straight-through cable has the same pinout on both ends. Each pin is connected to the corresponding pin on the other end.

Traditionally used to connect **different types of devices**, such as: 
- PC (MDI) → Switch (MDI-X)
- Router (MDI) → Switch (MDI-X)
```text
  End A                  End B
┌───────┐              ┌───────┐
│   1   │──────────────│   1   │
│   2   │──────────────│   2   │
│   3   │──────────────│   3   │
│   6   │──────────────│   6   │
└───────┘              └───────┘
```
#### Crossover Cable
A crossover cable swaps the Tx and Rx pairs between the two ends. The transmit pair on one device connects to the receive pair on the other.

Traditionally used to connect **similar types of devices**, such as: 
- PC (MDI) → PC (MDI)
- Switch (MDI-X) → Switch (MDI-X)
```text
  End A                  End B
┌───────┐              ┌───────┐
│   1   │──────────────│   3   │
│   2   │──────────────│   6   │
│   3   │──────────────│   1   │
│   6   │──────────────│   2   │
└───────┘              └───────┘
```
### Interfaces
#### MDI and MDI-X
MDI (Medium-Dependent Interface) defines which Ethernet pairs a device uses for transmitting (Tx) and receiving (Rx). Traditionally used by end devices such as **PCs, routers and firewalls**.

MDI-X (Medium-Dependent Interface Crossover) reverses the Tx/Rx pair assignments compared with MDI. Traditionally used by intermediate devices such as **switches and hubs**.

Because MDI and MDI-X use opposite Tx/Rx assignments, a **straight-through cable** can connect them directly.
```text
   MDI                     MDIX
┌────────┐              ┌────────┐
│ 1,2 Tx │──────────────│ 1,2 Rx │
│ 3,6 Rx │──────────────│ 3,6 Tx │
└────────┘              └────────┘
```
#### Auto-MDI-X
Auto-MDI-X (Automatic MDI/MDI-X) is an **Ethernet feature** that automatically detects and adjusts the Tx/Rx pair configuration, allowing Ethernet devices to communicate without requiring a specific cable type.
- Determines whether the connected device is using MDI or MDI-X.
- Automatically swaps the Tx/Rx pairs when necessary.
- Commonly supported on modern PCs, routers and switches.
```text
    Device A                       Device B
┌───────────────┐              ┌───────────────┐
│  MDI / MDI-X  │──────────────│  MDI / MDI-X  │
└───────────────┘              └───────────────┘
        │                              │
        └── Auto-MDI-X Handles Tx/Rx ──┘
```

### Cabling
Fiber-optic cables transmit data using **light through glass or plastic fiber** and are **immune to EMI**.
#### MMF (Multi-Mode Fiber)
MMF is a type of fiber-optic cable with a **larger core** that allows multiple angles (modes) of light to travel through the fiber. It is mainly used for **shorter-distance network connections**.
- Larger core than SMF (Single-Mode Fiber).
- Allows multiple angles of light to enter the core.
- Allows longer cables than UTP/STP, but shorter cables than SMF.
- Cheaper than SMF due to cheaper LED-based small form-factor pluggable (SFP) transmitters.
- Commonly used in LANs.
#### SMF (Single-Mode Fiber)
SMF is a type of fiber-optic cable with a **very small core** that allows essentially one angle of light to travel through the fiber. It is designed for **long-distance, high-bandwidth communication**.
- Very small core.
- Light enters at a single angle to the core.
- Allows longer than both UTP/STP and MMF.
- More expensive than MMF due to more expensive laser-based SFP transmitters.
- Commonly used in WANs.
