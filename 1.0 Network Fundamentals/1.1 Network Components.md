# 1.1 Network Components
## Introduction
**Computer Network**: A digital telecommunications network which allows nodes to share resources.

**Client**: A device that accesses a service made available by a server.

**Server**: A device that provides functions or services for clients.
## Routers
Routers are devices that **connect different networks and forwards IP packets** between them.
- Usually have fewer network interfaces than switches.
- Connect different LANs/networks.
- Maintain routing tables to determine the best path.
- Use IP addresses to make forwarding/routing decisions.
- Can provide connectivity to the Internet.
- Operate primarily at Layer 3.
## Switches
Switches **connect devices within the same LAN and forward Ethernet frames** between them.
- Have many network interfaces/ports for end hosts to connect to.
- Provide connectivity between devices within the same LAN.
- Learn MAC addresses by examining the source MAC address of incoming frames.
- Maintain a MAC address table to determine where frames should be forwarded.
- Do not provide connectivity between LANs or over the internet.
- Operate primarily at Layer 2.
### Layer 2 Switches
A layer 2 switch primarily operates using **Ethernet frames and MAC addresses**.
- Connects devices within a LAN.
- Learns MAC addresses.
- Stores MAC addresses in a **MAC address table**.
- Can create VLANs.
### Layer 3 Switches
A layer 3 switch can route traffic between VLANs without requiring a separate router.
- IP addresses can be assigned to its interfaces, like a router.
- Supports static routing between different networks.
- Forwards traffic based on IP addresses in addition to MAC addresses.
- Enables routing between VLANs or subnets.
### Layer 2 vs Layer 3 Switches
|         /          |   Layer 2 Switch    |        Layer 3 Switch        |
| :----------------: | :-----------------: | :--------------------------: |
|     OSI Layer      | Data Link (Layer 2) |      Network (Layer 3)       |
|     Forwarding     |    MAC Addresses    | MAC Addresses & IP Addresses |
|      Routing       |         No          |          IP Routing          |
|    VLAN Support    |         Yes         |             Yes              |
| Inter-VLAN Routing |         No          |             Yes              |
|     Protocols      |    Ethernet, STP    |     Ethernet, STP, OSPF      |
## Firewalls
A firewall is a network security system that monitors and controls incoming and outgoing network traffic based on configurable security rules.
### Network Firewalls (Hardware)
Network firewalls **protect an entire network or network segment** by controlling traffic between different networks.
- Monitor and control network traffic based on configured rules.
- Can be placed inside the network or outside the network.
- Can filter traffic based on factors such as IP addresses, ports, protocols, and connection state.
- Are known as **Next-Generation Firewalls** when they include more modern and advanced filtering capabilities.
### Host-Based Firewalls (Software)
Host-based firewalls **run directly on an individual device** and control network traffic to and from that device.
- Are software applications that filter traffic entering and exiting a host machine, like a PC.
- Protect the **individual host** rather than an entire network.
- Can have rules specific to applications, ports, IP addresses, and network connections.
