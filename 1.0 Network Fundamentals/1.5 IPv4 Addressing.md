# 1.5 IPv4 Addressing
## Introduction
### OSI Model - Network Layer (L3)
- Provides connectivity between end hosts on **different networks**, such as outside the LAN.
- Uses **IP addresses for logical addressing**.
- Determines the best path between the source and destination.
- Routers operate primarily at this layer and forward packets between networks.
