# 1.6 Subnetting
## Introduction
**CIDR (Classless Inter-Domain Routing)** is a method of IP address allocation that allows more efficient use of IP addresses. Unlike traditional class-based addressing, CIDR allocates IP addresses based on a network prefix rather than a fixed class.

## VLSM (Variable-Length Subnet Masking)
VLSM is a subnetting technique that **divides an IP network into subnets of different sizes**. Unlike fixed-length subnet masking (FLSM), which uses the same subnet mask for all subnets, **VLSM uses multiple subnet masks within the same network** according to the number of hosts required by each subnet.
### Step-by-Step Procedure
![VLSM Network Topology](../Attachments/Images/VLSM%20Network%20Topology.png)
#### 1. Determine Required Block Sizes
- Tokyo LAN A → 110 Hosts (/25 - 126 Usable Addresses)
- Tokyo LAN B → 8 Hosts (/28 - 14 Usable Addresses)
- Toronto LAN A → 29 Hosts (/27 - 30 Usable Addresses)
- Toronto LAN B → 45 Hosts (/26 - 62 Usable Addresses)
- Point-to-Point → 2 Hosts (/30 - 2 Usable Addresses)
