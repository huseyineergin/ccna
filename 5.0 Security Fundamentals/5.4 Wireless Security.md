# 5.4 Wireless Security
## Authentication Methods
### Open Authentication
Open authentication allows a device to connect without requiring a password or verifying the user's identity.
- The client sends an authentication request, which the access point (AP) accepts.
- It is **not** a secure authentication method.
- After the client is authenticated and associated with the AP, additional authentication methods can be required before network access is granted.
- It is part of the IEEE 802.11 standard.
### WEP (Wired Equivalent Privacy)
WEP is an **outdated** Wi-Fi security protocol that uses RC4 encryption and a shared key to protect wireless data.
- It provides authentication and encryption for wireless traffic.
- It uses the **RC4** algorithm for encryption.
- It is a **shared key protocol**, requiring the sender and receiver to use the same key.
	- WEP keys can be 40 or 104 bits long.
	- WEP keys are combined with a 24-bit **initialization vector (IV)**, resulting in total lengths of 64 or 128 bits.
- WEP is part of the IEEE 802.11 standard.

### EAP (Extensible Authentication Protocol)
EAP is an authentication framework that supports multiple methods for verifying the identity of users or devices on wireless and wired networks.
- It defines a standard set of authentication functions that are used by the various EAP methods.
- EAP is integrated with IEEE 802.1X, which provides port-based network access control.

802.1X is used to limit network access for clients connected to a LAN or WLAN until they authenticate.
- **Supplicant**: The device that wants to connect to the network.
- **Authenticator**: The device that provides access to the network.
- **Authentication Server (AS)**: The device that receives client credentials and permits/denies access.

![Wireless Security - EAP](../Attachments/Images/Wireless%20Security%20-%20EAP.png)
#### LEAP (Lightweight EAP)
LEAP is a wireless authentication method that uses username and password credentials to authenticate users.
- It was developed by Cisco as an improvement over WEP.
- Clients must provide a username and password to authenticate.
- Mutual authentication is performed by having the client and server send challenge phrases to each other.
- **Dynamic WEP keys** are used, meaning the keys change frequently.
- Like WEP, LEAP is considered vulnerable and should not be used anymore.

![Wireless Security - LEAP](../Attachments/Images/Wireless%20Security%20-%20LEAP.png)
#### EAP-FAST (EAP Flexible Authentication via Secure Tunneling)
EAP-FAST is a authentication method that uses a secure tunnel to protect user credentials during authentication with a network server.
- It was developed by Cisco.
- It consists of three phases:
	1. A **PAC (Protected Access Credential)** is generated and provided to the client by the server.
	2. A secure TLS tunnel is established between the client and the authentication server.
	3. The client and server exchange further authentication and authorization information through the secure TLS tunnel.

![Wireless Security - EAP-FAST](../Attachments/Images/Wireless%20Security%20-%20EAP-FAST.png)
#### PEAP (Protected EAP)
PEAP is a wireless authentication method that uses a secure tunnel to protect user credentials during authentication with a network server.
- Like EAP-FAST, PEAP establishes a secure TLS tunnel between the client and the server.
- Instead of using a PAC, the server uses a digital certificate.
- The client uses this certificate to authenticate the server.
- The certificate is also used to establish the TLS tunnel.
- Because only the server provides a certificate for authentication, the client must still be authenticated within the secure tunnel.

![Wireless Security - PEAP](../Attachments/Images/Wireless%20Security%20-%20PEAP.png)
#### EAP-TLS (EAP Transport Layer Security)
EAP-TLS is a wireless authentication method that uses digital certificates on both the client and server to provide mutual authentication and secure communication.
- Whereas PEAP requires a certificate only on the authentication server, EAP-TLS requires a certificate on both the authentication server and every client device.
- EAP-TLS is considered the most secure wireless authentication methods, but it is more difficult to implement than PEAP because every client device needs a certificate.
- Because the client and server authenticate each other using digital certificates, there is no need for additional client authentication within the TLS tunnel.
- The TLS tunnel is still used to exchange encryption key information.

## Encryption and Integrity Methods
### TKIP (Temporal Key Integrity Protocol)
TKIP is a security protocol developed to address WEP's weaknesses by introducing dynamic encryption keys and stronger data integrity checks.
- A **MIC (Message Integrity Check)** is added to protect message integrity.
	- The MIC includes the sender's MAC address to identify the frame's source.
- A **key-mixing algorithm** generates a unique WEP key for each frame.
- The initialization vector is increased from 24 bits to 48 bits, making brute-force attacks more difficult.
- A timestamp is added to the MIC to help prevent replay attacks, which involve retransmitting previously captured frames.
- A TKIP sequence number tracks frames sent from each source MAC address, providing additional protection against replay attacks.
- TKIP is used in **WPA (Wi-Fi Protected Access)**.
### CCMP (Counter/CBC-MAC Protocol)
CCMP is a security protocol that uses AES encryption to provide data confidentiality, integrity and authentication.
- CCMP requires hardware support. Older hardware designed only for WEP/TKIP cannot use CCMP.
- CCMP combines two cryptographic mechanisms to provide encryption and message integrity:
	1. **AES (Advanced Encryption Standard)** is used for encryption.
		- AES is a widely used encryption standard.
		- AES supports multiple modes of operation. CCMP uses **counter mode** for encryption.
	2. **CBC-MAC (Cipher Block Chaining Message Authentication Code)** is used as a MIC to ensure the integrity of messages.
- CCMP is used in **WPA2**.
### GCMP (Galois/Counter Mode Protocol)
GCMP is a security protocol that provides data confidentiality, integrity and authentication while protecting wireless communications against tampering and replay attacks.
- GCMP is more secure and efficient than CCMP.
	- Its increased efficiency allows higher data throughput than CCMP.
- GCMP combines two cryptographic mechanisms:
	1. AES counter mode is used for encryption.
	2. **GMAC (Galois Message Authentication Code)** is used as a MIC to ensure the integrity of messages.
- GCMP is used in **WPA3**.
## WPA (Wi-Fi Protected Access)
WPA, WPA2 and WPA3 are the three security certification programs developed by the Wi-Fi Alliance to secure wireless computer networks.
- To receive WPA certification, equipment must be tested at authorized testing laboratories.
- All three support two authentication modes:
	- **Personal Mode**: Uses a **pre-shared key (PSK)** for authentication. An example of personal mode is entering a password to authenticate when connecting to a home Wi-Fi network.
		- This mode is common in small networks.
		- The PSK itself is not transmitted over the air. A four-way handshake is used to establish authentication and the PSK is used to derive encryption keys.
	- **Enterprise Mode**: Uses IEEE 802.1X with an authentication server, such as a RADIUS server.
		- No specific EAP method is specified, so all are supported.

The **WPA** certification was developed after WEP was found to be vulnerable. It includes the following protocols:
- TKIP provides encryption and message integrity checks.
- IEEE 802.1X is used in enterprise mode, while a PSK is used in personal mode.

The **WPA2** was released in 2004 and includes the following protocols:
- CCMP ovides encryption and message integrity checks.
- IEEE 802.1X is used in enterprise mode, while a PSK is used in personal mode.

The **WPA3** was released in 2018 and includes the following protocols:
- GCMP provides encryption and message integrity checks.
- IEEE 802.1X is used in enterprise mode, while a PSK is used in personal mode.
- WPA3 also provides several additional security features, such as:
	- **PMF (Protected Management Frames)**: Protects 802.11 management frames against forgery and certain replay attacks.
	- **SAE (Simultaneous Authentication of Equals)**: Protects the four-way handshake when using personal mode authentication.
	- **Forward Secrecy**: Helps prevent data from being decrypted after it has been transmitted over the air.
