# 5.2 Security Fundamentals
## Introduction
The principles of the **CIA triad** form the foundation of security:
- **Confidentiality**
	- Only authorized users should be able to access data.
	- Some information is public and can be accessed by anyone, while other information is confidential and should only be accessible to specific individuals.
- **Integrity**
	- Data should not be modified by unauthorized users.
	- Data should remain accurate and authentic.
- **Availability**
	- Networks and systems should remain operational and accessible to authorized users.

A **vulnerability** is a potential weakness that can compromise the confidentiality, integrity or availability of a system or information.
- A potential weakness is not a problem on its own.

An **exploit** is a method that can be used to take advantage of a vulnerability.
- An exploit is not necessarily a problem on its own.

A **threat** is the potential of a vulnerability to be exploited.
- A hacker exploiting a vulnerability in the system is a threat.

A **mitigation technique** is a measure that can reduce the risk posed by threats.
- Mitigation techniques should be implemented wherever a vulnerability could be exploited, including client devices, servers, switches, routers, firewalls and other network components.
## Common Attacks
### Denial-of-Service (DoS) Attack
A denial-of-service attack attempts to make a system or network unavailable to legitimate users by overwhelming it with requests or disrupting its operation.
- DoS attacks threaten the **availability** of a system.
- One common DoS attack is **TCP SYN flood**.
	- The attacker sends a large number of TCP SYN messages to the target.
	- The target responds to each SYN with a SYN-ACK message.
	- The attacker never sends the final ACK to complete the TCP three-way handshake.
	- The incomplete connections fill up the target's TCP connection table.
	- The attacker continues sending SYN messages.
	- Eventually, the target can no longer establish legitimate TCP connections.
- In a **DDoS (Distributed Denial-of-Service)** attack, the attacker infects multiple computers with malware and uses them to launch a coordinated denial-of-service attack against a target.
	- This group of infected computers is called a **botnet**.
### Spoofing
Spoofing is when an attacker disguises their identity or impersonates a trusted source to deceive a person, computer system, or network. It is used in various types of attacks.
- **Address spoofing** involves using a fake source address, such as an IP or MAC address.
- An example is a **DHCP exhaustion** attack.
	- The attacker uses spoofed MAC addresses to flood the DHCP server with DHCP discover messages.
	- The server's DHCP address pool becomes exhausted, preventing other devices from obtaining IP addresses and causing a denial-of-service.
	- This attack threatens the **availability** of a system.
### Reflection and Amplification Attacks
A reflection attack is an attack in which an attacker sends requests to third-party servers using the target’s spoofed IP address.
- In a **reflection attack**, the attacker sends traffic to a reflector while spoofing the source IP address of the packets to make it appear as though they came from the target.
- The reflector sends its replies to the target’s IP address.
- If the volume of traffic sent to the target is large enough, it can result in a denial-of-service.

A reflection attack becomes an **amplification attack** when a small amount of traffic sent by the attacker triggers a much **larger volume of traffic from the reflector to the target**.

### Man-in-the-Middle (MITM) Attack
A man-in-the-middle attack is an attack in which an attacker secretly intercepts and potentially modifies communication between two parties who believe they are communicating directly with each other.
- A common example is **ARP spoofing**, also known as **ARP poisoning**.
	- A host sends an ARP request asking for the MAC address of another device.
	- The target of the request sends an ARP reply, informing the requester of its MAC address.
	- The attacker sends a forged ARP reply after the legitimate device's reply.
	- If the attacker's reply arrives last, it overwrites the legitimate entry in the ARP table.
	- In the host's ARP table, the entry for the target's IP address will contain the attacker's MAC address.
	- When the host tries to send traffic to the target, it will be forwarded to the attacker instead.
	- The attacker can inspect the messages and then forward them to the target.
	- The attacker can also modify the messages before forwarding them to the target.
	- This compromises the **confidentiality** and **integrity** of communications between the host and the target.

### Reconnaissance Attack
A reconnaissance attack is an attack in which an attacker gathers information about a target system or network to identify potential vulnerabilities and plan future attacks.
- This is often publicly available information.
	- `nslookup` to find the IP address of a website.
	- A WHOIS query to find email addresses, phone numbers, physical addresses and other information.
### Malware
Malware is any software or code designed to damage, disrupt or exploit a computer system, network or device.
- **Viruses** infect other software (a host program). They spread as users share the infected software. They typically corrupt or modify files on the target computer.
- **Worms** do not require a host program. They are standalone malware that can spread on their own, without user interaction. Their spread can congest the network, while their payloads can cause additional harm to target devices.
- **Trojan horses** are malicious programs disguised as legitimate software. They are often spread through user interaction, such as opening email attachments or downloading files from the Internet.
- Malware can exploit various vulnerabilities in the target system.
### Social Engineering Attacks
Social engineering attacks involve manipulating or deceiving people into revealing confidential information, performing unauthorized actions, or granting access to systems.
- They involve psychological manipulation to make the target reveal confidential information or perform some action.
- **Phishing** typically involves fraudulent emails that appear to come from a legitimate business and contain links to a fraudulent website that seems legitimate. Users are told to login to the fraudulent website, providing their login credentials to the attacker.
	- **Spear phishing** is a more targeted form of phishing, such as one aimed at employees of a specific company.
	- **Whaling** is phishing targeted at high-profile individuals.
	- **Vishing** is phishing performed over the phone.
	- **Smishing** is phishing using SMS text messages.
- **Watering hole** attacks compromise websites that the target frequently visits. If a malicious link is placed on a website the target trusts, they might not hesitate to click it.
- **Tailgating** involve entering restricted areas by following an authorized person through a secured entrance without permission.
### Password Attacks
Password attacks involve attempts to obtain, guess, crack or misuse a user's password to gain unauthorized access to accounts, systems or networks.
- Usernames are often easy to guess, so security relies on the strength and secrecy of the password.
- Attackers can obtain a user's password through several methods:
	- **Guessing**: Trying to guess the user's password.
	- **Dictionary Attack**: A program tries words from a dictionary or a list of common passwords to find the target's password.
	- **Brute Force Attack**: A program tries every possible combination of letters, numbers, and special characters to find the target's password.
- Strong password should contain:
	- At least 8 characters, preferably more.
	- A mix of lowercase and uppercase letters.
	- A mix of letters and numbers.
	- One or more special characters.
## MFA (Multi-Factor Authentication)
MFA is a security mechanism that requires users to provide two or more different types of verification factors to verify their identity before accessing an account, system or network.
- It usually involves providing two of the following (**two-factor authentication**):
	- A username/password combination, a PIN, etc.
	- Approving a notification on a phone, scanning an access badge, etc.
	- Biometrics, such as a face scan, palm scan, fingerprint scan or retina scan.
- Requiring multiple authentication factors greatly increases security. Even if an attacker obtains the target's password, they will not be able to access the target's account without the additional authentication factor.
## Digital Certificates
Digital certificates are electronic documents used to verify the identity of an individual, organization or device and establish trust in digital communications.
- They are mainly used for websites to verify that the website being accessed is legitimate.
- Entities that want a certificate to prove their identity send a **CSR (Certificate Signing Request)** to a **CA (Certificate Authority)**, which generates and signs the certificate.
## AAA (Authentication, Authorization, Accounting)
AAA is a security framework used to control and monitor access to computer systems and networks.
- **Authentication** is the process of verifying a user’s identity.
	- Signing in or signing up.
- **Authorization** is the process of granting a user the appropriate access and permissions.
	- Granting the user access to certain files or services while restricting access to others.
- **Accounting** is the process of recording a user’s activities on the system.
	- Logging when a user makes changes to a file.
- Enterprises typically use a AAA server to provide AAA services.
	- **ISE (Identity Services Engine)** is Cisco’s AAA server.
- AAA servers usually support the following two AAA protocols:
	- **RADIUS**: An open standard protocol. Uses **UDP ports 1812 and 1813**.
	- **TACACS+**: A Cisco propriety protocol. Uses **TCP port 49**.
## Security Programs
A security program is a set of policies, procedures and practices designed to protect an organization’s information, systems, networks, and assets from security threats and unauthorized access.
- **User awareness** programs are designed to make employees aware of potential security threats and risks.
	- For example, a company might send simulated phishing emails to make employees to click a link and enter their login credentials.
	- Employees who fall for the simulated phishing emails are informed that it is an awareness exercise and reminded to be cautious of phishing attempts.
- **User training** programs are more formal than user awareness programs.
	- For example, dedicated training sessions that teach users about corporate security policies, how to create strong passwords and how to avoid potential threats.
- **Physical access control** protects equipment and data from potential attackers by allowing only authorized users to enter restricted areas.
	- Multifactor locks can protect access to restricted areas.
