# 5.1 ACLs
## Introduction
**ACLs (Access Control Lists)** are sets of rules used by a network device to permit or deny network traffic.
- They function as packet filters, instructing the device to permit or discard traffic.
- They can filter traffic based on IP addresses, ports, protocols, etc.
- They are an **ordered** sequence of ACEs.
- Configuring an ACL in global configuration mode does not make it take effect. The ACL must be applied to an interface.
- They are applied either **inbound** or **outbound**.
- If a packet matches one of the ACEs in the ACL, the device takes the specified action and stops processing the ACL. All entries below the matching entry are ignored.
- A **maximum of one ACL** can be applied to a single interface **in each direction**.
- If a packet does not match any ACE in an ACL, it is **implicitly denied**.

An **ACE (Access Control Entry)** is one individual rule inside an ACL.
## Standard ACLs
A standard ACL filters traffic based **only on the source IPv4 address**.
- Standard ACLs should be applied as close to the destination as possible.
### Standard Numbered ACLs
A standard numbered ACL is identified by a **number**.
- Different types of ACLs have different ranges of numbers that can be used.
	- Standard ACLs can use the number ranges 1–99 and 1300–1999.
- `access-list <access-list-number> {deny | permit} <source-ip> <wildcard-mask>` command is used to configure a standard numbered ACL.
	- `access-list 10 deny 192.168.1.0 0.0.0.255`
	- `access-list 10 permit any`
- `ip access-group <access-list-number> {in | out}` command is used to apply a standard numbered ACL to an interface.
	- `ip access-group 10 out`
### Standard Named ACLs
A standard named ACL is identified by a **name** rather than a number.
- Standard named ACLs are configured by entering **standard named ACL configuration mode** and then configuring each entry in that mode.
	- `ip access-list standard <access-list-name>` command is used to enter standard named ACL configuration mode.
		- `ip access-list standard BLOCK_HR`
- `[entry-number] {deny | permit} <source-ip> <wildcard-mask>` command is used to configure an ACE in a standard named ACL.
	- `5 deny 192.168.1.0 0.0.0.255`
	- `permit any`
- `ip access-group <access-list-name> {in | out}` command is used to apply a standard named ACL to an interface.
	- `ip access-group BLOCK_HR in`
