# 3.3 First-Hop Redundancy Protocols
## Introduction
First-Hop Redundancy Protocols (FHRPs) are used to provide a **backup default gateway** for hosts on a LAN.
- If hosts have only one default gateway and that router fails, the hosts lose access to other networks, even if another router is available.
- FHRPs allow **multiple routers to work together and present a single virtual default gateway**, using a virtual IP address and virtual MAC address, to the hosts.
- The new active router sends gratuitous ARP messages so that switches can update their MAC address tables.
- FHRPs are **not preemptive** by default. The current active router will not automatically give up its role, even if the formar active router recovers.

A **gratuitous ARP (GARP)** is an ARP response sent without being corresponding request. It is sent as a **broadcast**, as a way for a node to **announce or update its IP to MAC mapping to the entire network**.
## HSRP (Hot Standby Router Protocol)
HSRP is a Cisco proprietary FHRP that provides **default gateway redundancy** for hosts on a LAN.
- An **active** router and a **standby** router are elected.
- It has two versions, namely version 1 and version 2.
	- Version 2 adds IPv6 support and increases the number of groups that can be configured.
- HSRP messages are **multicast** to:
	- *224.0.0.2*, for version 1.
	- *224.0.0.102*, for version 2.
- HSRP virtual MAC addresses are:
	- *0000.0c07.ac**XX***, for version 1. (**XX** = HSRP Group Number)
	- *0000.0c09.f**XXX***, for version 2. (**XXX** = HSRP Group Number)
- In a situation with multiple subnets or VLANs, a different active router can be configured for each subnet or VLAN to load balance.
## VRRP (Virtual Router Redundancy Protocol)
VRRP is an IETF standard FHRP that provides **default gateway redundancy** for hosts on a LAN.
- A **master** router and a **backup** router are elected.
- VRRP messages are **multicast** to:
	- *224.0.0.18*, for IPv4.
	- *ff02::12*, for IPv6.
- VRRP virtual MAC address is *0000.5e00.01**XX***. (**XX** = VVRP Group Number)
- In a situation with multiple subnets or VLANs, a different master router can be configured for each subnet or VLAN to load balance.
## GLBP (Gateway Load Balancing Protocol)
GLBP is a Cisco proprietary FHRP that provides **default gateway redundancy** and **load balancing** by allowing multiple routers to share the forwarding of traffic for a single virtual gateway.
- It can load balance traffic among multiple routers within a single subnet.
- An **active virtual gateway (AVG)** is elected. Then, up to four **active virtual forwarders (AVFs)** are assigned by the AVG. The AVG itself can be AVF as well.
- Each AVF acts as the default gateway for a portion of the hosts in the subnet.
- GLBP message is **multicast** to *224.0.0.102* for IPv4.
- GLBP virtual MAC address is *0007.b400.**XXYY***. (**XX** = GLBP Group Number, **YY** = AVF Number)
