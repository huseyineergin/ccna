# 3.1 Routing Fundamentals
## Introduction
**Routing** is the process that routers use to determine the path that packets should take over a network to reach their destination.
- Routers store routes to all of their known destinations in a **routing table**.

A **route** is a rule that tells the router where to send a packet to reach a particular destination network.

**Dynamic Routing**: Routers use dynamic routing protocols, such as OSPF, to share routing information with each other automatically and build their routing tables.

**Static Routing**: Routers use manually configured routes, where an administrator manually configures the paths that packets should take to reach different networks.
## Default Gateway
A default gateway is a network device (usually a router) that a host uses to send data to destinations **outside its own local network**.
- Provides a path from the local network to external networks.
- Packets destined for another network are sent to the default gateway first.
## Default Route
A default route is a configuration that establishes a forwarding rule for packets **when no specific address of a next-hop host is available** from the routing table or other routing mechanisms.
- It is the **least specific** route because it includes all IP addresses.
- It is used only when no more specific route matches.
- It generally points to another router (next-hop router).
- IPv4 = *0.0.0.0/0*, IPv6 = *::/0*
## Connected and Local Routes
Routers automatically extract two types of routing information from the IP configuration assigned to their interfaces. These types are **Connected (C)** and **Local (L)** routes. If an interface’s state or IP configuration changes, it automatically updates related Connected and Local routes in the routing table.
```text
R1#show ip route
...
192.168.1.0/24 is variably subnetted, 2 subnets, 2 masks
	C 192.168.1.0/24 is directly connected, GigabitEthernet0/0
	L 192.168.1.1/32 is directly connected, GigabitEthernet0/0
```
>R1 G0/0 IP Address = *192.168.1.1/24*, Network Address = *192.168.1.0/24*
### Connected Routes
Connected routes are the specific **network that an interface belongs to**.
- A connected route is a route to the network the interface is connected to.
- It provides a route to all hosts in that network.
- R1 knows that if it needs to forward a packet to any host on the *192.168.1.0/24* network, it should use the G0/0 interface.
### Local Routes
A local route is a route on the routing table that is the **actual IP address of the router interface**.This IP is the literal identifier for that port.
- A local route is a route to the exact IP address configured on the interface.
- A /32 netmask is used to specify the exact IP address.
- Even though R1's G0/0 IP Address is configured as *192.168.1.1/24*, the local route is to *192.168.1.1/32*.
- R1 knows that if it receives a packet destined for *192.168.1.1/32*, the packet is destined for itself.
### Route Selection
When a router needs to forward a packet, it examines its routing table and selects the best matching route for the packet's destination IP address. The router primarily **uses prefix length to determine which route is the most specific match**.
- A **longer prefix** means a more specific route. A **shorter prefix** means a less specific route.
- If multiple routes match the destination, the router chooses the route with the **longest prefix match**.
## Static Routes
A static route is a **manually configured route** that tells a router where to forward packets for a particular destination network.
- Not learned through a routing protocols.
- Remains unchanged unless manually modified or removed.
- Commonly used in small networks or for specific routing requirements.
