# 4.3 DHCP
## DHCP (Dynamic Host Configuration Protocol)
DHCP is a network protocol that automatically assigns IP addresses and other network settings to devices when they connect to a network.
- DHCP allows hosts to automatically obtain various network configuration settings, such as an IP address, subnet mask, default gateway and DNS server, without requiring manual configuration.
- It is commonly used for client devices such as PCs.
	- `ipconfig /release` command releases the current DHCP-assigned IP address and configuration on Windows.
	- `ipconfig /renew` command requests a new IP address and configuration from the DHCP server on Windows.
- Devices such as routers and servers are usually configured manually.
- DHCP servers **lease** IP addresses to clients. These **leases are usually temporary**, and clients must give up their assigned IP addresses when the leases expire.
- DHCP **servers** use **UDP port 67**. DHCP **clients** use **UDP port 68**.
- In small networks, the router often acts as the DHCP server.
- In larger networks, the DHCP server is usually a Windows or Linux server.
- Cisco routers can act as DHCP servers.
	- `ip dhcp excluded-address <start-ip> <end-ip>` command excludes a range of IP addresses from being assigned to DHCP clients.
	- `ip dhcp pool <pool-name>` command creates a DHCP address pool.
	- `network <net-addr> <netmask>` command specifies the subnet of addresses to be assigned to DHCP clients.
	- `dns-server <ip-addr>` command specifies the DNS server.
	- `domain-name <domain-name>` command specifies the domain name of the network.
	- `default-router <ip-addr>` command specifies the default gateway.
	- `lease {<days> <hours> <minutes> | infinite}` command specifies the lease time.
	- `show ip dhcp binding` command displays the IP addresses leased to DHCP clients and their associated client identifiers.
- `ip address dhcp` command configures a router interface to automatically obtain an IP address from a DHCP server.
## DHCP Messages
DHCP messages are used by clients and servers to exchange information during the IP address assignment process.
1. **Discover**: The client **broadcasts** a message to find available DHCP servers. The client does not yet have an IP address.
2. **Offer**: The DHCP server offers an available IP address to the client.
3. **Request**: The client **broadcasts** a message to request the offered IP address. This message also informs other DHCP servers that their offers have not been selected.
4. **Acknowledgement**: The DHCP server confirms the IP address assignment, allowing the client to join the network.
- **Release**: The client sends a message to the DHCP server to release its assigned IP address, making it available for other devices to use.

## DHCP Relay
DHCP relay is the process of forwarding DHCP messages between clients and a DHCP server on a different subnet.
- **DHCP relay agent** forwards DHCP messages between the networks.
	- `ip helper-address <ip-addr>` command configures the IP address of the DHCP server. This command should be applied to the router interface that receives DHCP broadcast messages from hosts.
