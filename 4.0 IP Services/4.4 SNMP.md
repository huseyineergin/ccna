# 4.4 SNMP
## SNMP (Simple Network Management Protocol)
SNMP is a network protocol used to monitor and manage devices on an IP network, such as routers, switches, servers and firewalls.
- There are two main types of devices in SNMP:
	- **Managed Devices**: The devices managed by SNMP.
	- **NMS (Network Management Station)**: The device managing the managed devices. The NMS is the SNMP server.
- There are three main operations used in SNMP:
	- Managed devices can notify the NMS of events, such as interfaces going up or down.
	- The NMS can request information about the current status of managed devices, such as CPU usage.
	- The NMS can instruct managed devices to change aspects of their configuration, such as the IP address of an interface.
- SNMP agents use **UDP port 161**, while SNMP managers use **UDP port 162**.
## SNMP Components
The **SNMP manager** is the component of the NMS that communicates with SNMP agents on managed devices.
- It sends requests to retrieve information and, where supported, modify managed variables.
- It receives and processes responses from agents, as well as asynchronous notifications such as traps and informs.

The **SNMP application** provides the interface through which network administrators monitor and manage network devices.
- It displays alerts, statistics, graphs and device status, and allows administrators to initiate monitoring or management operations.
- It uses the SNMP manager functionality to communicate with managed devices.

The **SNMP agent** is software running on a managed device that responds to requests from the SNMP manager.
- It provides access to management information and processes supported operations.
- It can send notifications, such as traps or informs, to the manager when specified events occur.

The **management information base (MIB)** is a structure that contains the variables managed by SNMP.
- Each variable is identified by an **object identifier (OID)**.
- These objects represent information such as interface status, traffic, CPU usage and temperature.

## OIDs (Object Identifiers)
An object identifier is a unique, numerical identifier used to identify a specific managed object in a network device.
- OIDs are organized in a hierarchical structure.
	- `1.3.6.1.2.1.1.5.0` identifies the SNMP object `sysName.0`, which represents the device's system name.
- An OID can identify a device's system name, an interface's operational status or an interface's traffic counter.
- SNMP uses OIDs to specify exactly which piece of information the manager wants to retrieve or modify from an SNMP agent.
## SNMP Versions
SNMP has three main versions, namely **SNMPv1**, **SNMPv2c** and **SNMPv3**. They differ in functionality, performance, authentication and security.
- SNMPv1 is the original version of SNMP.
- SNMPv2c allows the NMS to retrieve large amounts of information in a single request, so it is more efficient.
	- The "c" refers to the community strings used as passwords in SNMPv1. These were removed in SNMPv2 and reintroduced in SNMPv2c.
- SNMPv3 is a much more secure version of SNMP that supports strong **encryption** and **authentication**.
## SNMP Messages
SNMP messages are protocol data units (PDUs) exchanged between an SNMP manager and an SNMP agent to monitor and manage network devices.
- **Get**: A request sent from the manager to the agent to retrieve the value of a variable or multiple variables. The agent will send a response message with the current value of each variable.
- **GetNext**: A request sent from the manager to the agent to discover the available variables in the MIB.
- **GetBulk**: A more efficient version of the GetNext message. It is introduced in SNMPv2.
- **Set**: A request sent from the manager to the agent to change the value of one or more variables. The agent will send a response message with the new values.
- **Trap**: A notification sent from the agent to the manager. The manager does not send a response message to acknowledge that it received the trap, so these messages are unreliable.
- **Inform**: A notification message that is acknowledged with a response message.
