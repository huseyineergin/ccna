# 4.8 NAT
## Introduction
IPv4 does not provide enough addresses for all the devices that need an IP address in the modern world. There are three main short-term solutions:
1. CIDR
2. Private IPv4 Addresses
3. NAT

RFC 1918 specifies the following IPv4 address ranges as private:
- *10.0.0.0/8*, from *10.0.0.0* to *10.255.255.255*.
- *172.16.0.0/12*, from *172.16.0.0* to 1*72.32.255.255*.
- *192.168.0.0/16*, from *192.168.0.0* to *192.168.255.255*.
## NAT (Network Address Translation)
NAT is a networking technique that allows a router or firewall to translate IP addresses in network traffic as packets move between networks.
- Its most common use is to allow multiple devices on a private network to share a single public IP address when accessing the Internet.
## Static NAT
Static NAT is a type of NAT that maps one private IP address to one public IP address using a fixed, permanent one-to-one mapping.
- An **inside local** IP address is mapped to an **inside global** IP address.
	- Inside Local: The IP address of the inside host, from the perspective of the local network.
		- The IP address actually configured on the inside host, usually a private address.
	- Inside Global: The IP address of the inside host, from the perspective of outside hosts.
		- The IP address of the inside host **after NAT**, usually a public address.
	- Outside Local: : The IP address of the outside host, from the perspective of the local network.
	- Outside Global: The IP address of the outside host, from the perspective of the outside network.
- Static NAT does not help preserve IP addresses, as it requires a one-to-one mapping of IP addresses.
- This one-to-one mapping also allows external hosts to access the internal host using the inside global address.
- `(config-if)#ip nat inside` command defines the interface as the inside interface for NAT.
- `(config-if#ip nat outside` command defines the interface as the outside interface for NAT.
- `(config)#ip nat inside source static <il-ip-addr> <ig-ip-addr>` command configures a static one-to-one NAT mapping between an inside local IP address and an inside global IP address.
- `#show ip nat translations` command displays the active NAT translation entries in the translation table.
- `#clear ip nat translation *` command clears all dynamic NAT translation entries from the NAT translation table.
- `#show ip nat statistics` command displays NAT statistics, including active translations, inside and outside interfaces and translation hits and misses.

## Dynamic NAT
Dynamic NAT is a type of NAT that automatically maps private IP addresses to public IP addresses selected from a configured pool.
- A NAT pool is used to define the available inside global addresses that can be used.
	- `ip nat pool <pool-name> <start-ip-addr> <end-ip-addr> netmask <netmask>` command defines a pool of inside global IP addresses available for dynamic NAT translations.
- An ACL is used to identify which traffic should be translated.
	- `access-list <acl-num> permit <src-ip> <wc-mask>` command identifies the inside local source IP addresses eligible for translation by dynamic NAT.
	- If the source IP address is **permitted** by the ACL, it will be translated.
	- If the source IP address is **denied** by the ACL, it will not be translated, but the traffic will not be dropped.
- Although the mappings are dynamically assigned, they are still one-to-one.
- If there aren't enough inside global IP addresses available, this is called **NAT pool exhaustion**.
	- If a packet from another inside host arrives and requires NAT, but no addresses are available, the router will drop the packet.
	- The host will be unable to access external networks until one of the inside global IP addresses becomes available.
	- Dynamic NAT entries will time out automatically if they are not used.
- `ip nat inside source list <acl> pool <pool-name>` command configures dynamic NAT by mapping source addresses permitted by the specified ACL to available addresses in the NAT pool.
## Dynamic PAT (Port Address Translation)
Dynamic PAT is a type of NAT that allows multiple devices to share a single public IP address by using different port numbers to distinguish their network connections. It is also called **NAT overload**.
- By using a unique port number for each communication flow, a single public IP address can be used by many different internal hosts.
- The router will keep track of which inside local address is using which inside global address and port.
- PAT is widely used in networks around the world because it allows multiple inside hosts to share a single public IP address, making it very effective at preserving public IP addresses.
- `ip nat inside source list <acl> pool <pool-name> overload` command enables dynamic PAT, allowing multiple inside local IP addresses to share addresses from the specified NAT pool.
- `ip nat inside source list <acl> interface <outside-int-id> overload` command configures dynamic PAT using the specified interface's IP address to translate multiple inside local addresses.
