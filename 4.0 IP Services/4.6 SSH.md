# 4.6 SSH
## Console Line Security
A password can be configured on the console line to access the CLI of a device via the console port.
- `(config)#line console 0` command enters line configuration mode.
- `(config-line)#password <password>` command configures a password on the console line.
- `(config-line)#login` command enables password authentication on the console line.
- `(config)#username <username> secret <secret>` command creates a local user account.
- `(config-line)#login local` command enables authentication using the device’s local username database.
- `(config-line)#exec-timeout <minutes> <seconds>` command configures the maximum period of inactivity before the device automatically terminates current session.
## Layer 2 Switch Management IP
A layer 2 switch management IP is an IP address assigned to a network switch so that it can be accessed remotely.
- An IP address can be assigned to an SVI to allow remote connections to the CLI using SSH or Telnet.
```text
SW1(config)#interface vlan 1
SW1(config-if)#ip address <ip-addr> <netmask>
SW1(config-if)#no shutdown
SW1(config-if)#exit
SW1(config)#ip default-gateway <ip-addr>
```
- `(config)#ip default-gateway <ip-addr>` command configures the default gateway so that the switch can communicate with devices on remote networks.
## Telnet
Telnet is a network protocol used to remotely access devices through a CLI over a network.
- Telnet has been largely replaced by SSH, which is more secure.
- Telnet transmits data in plain text. There is no encryption.
- A Telnet server listens on **TCP port 23**.
- `(config)#line vty <first-line-num> <last-line-num>` command enters line configuration mode for the specified VTY lines.
- `(config-line)#transport input telnet` command configures the VTY lines to accept incoming Telnet connections for remote CLI access.
- `(config-line)#access-class <acl> in` command applies an ACL to the VTY lines.
## SSH (Secure Shell)
SSH is a network protocol used to **securely** access remote devices through a CLI over a network.
- SSH was developed to replace less secure protocols like Telnet.
- SSH provices security features such as **data encryption** and **authentication**.
- An SSH server listens on **TCP port 22**.
- To enable and use SSH, an RSA key pair must be generated.
	- A hostname and a domain name must be configured on the device to generate the keys.
	- The keys are used for encryption, decryption, authentication and other security functions.
	- `(config)#crypto key generate rsa` command generates an RSA key pair for SSH on the device.
- `show version` command displays information about the device, including its IOS version.
	- IOS images that support SSH will have **K9** in their name.
- `#show ip ssh` command displays the SSH configuration and status on the device.
- `(config)#ip ssh version 2` command configures the device to use SSH version 2.
- `(config-line)#transport input ssh` command configures the VTY lines to accept incoming SSH connections for remote CLI access.
