# 4.2 DNS
## DNS (Domain Name System)
DNS is the system that translates human-readable names into IP addresses that computers use to find servers.
- DNS is used to resolve human-readable names into IP addresses.
- Machines don't use names, they use addresses.
- DNS servers can be configured manually or learned through DHCP.
- Devices store DNS server responses in a local DNS cache. This means they don't have to query the server every time they want to access a particular destination.
	- `ipconfig /all` command displays detailed information for all network adapters, including their IP addresses, DNS servers and DHCP settings on Windows.
	- `ipconfig /displaydns` command displays the contents of the local DNS resolver cache on Windows.
	- `ipconfig /flushdns` command clears the local DNS resolver cache on Windows.
- Standard DNS messages typically use UDP. TCP is used for DNS messages **larger than 512 bytes**. In both cases, **port 53** is used.
- A Cisco router can be configured as a DNS server.
	- `ip dns server` command is used to configure the device to act as a DNS server.
	- `ip host <hostname> <ip-addr>` command creates a static hostname-to-IP address mapping in the device's local host table.
	- `ip name-server <ip-addr>` command specifies the IP address of a DNS server that the device can use to resolve domain names.
	- `ip domain lookup` command enables DNS lookup, allowing the device to resolve domain names to IP addresses.
	- `ip domain name <domain-name>` command sets the default domain name used to complete unqualified hostnames during DNS lookups.
	- `show hosts` command displays configured DNS servers, domain name settings and cached hostname and IP address entries.
## DNS Records
DNS records are instructions stored in the domain name system that tell the internet how to handle a domain name.
- **A Record**: Maps a domain name to an IPv4 address.
- **AAAA Record**: Maps a domain name to an IPv6 address.
- **CNAME (Canonical Name) Record**: Points one domain name to another domain name.
- **MX Record**: Specifies the mail servers responsible for receiving emails.
- **TXT Record**: Stores any type of descriptive information in text format.
- **NS Record**: Identifies the authoritative nameservers for a domain.
- **SOA Record**: Contains administrative information about a DNS zone.
- **SRV Record**: Specifies the hostname and port for a particular service.
- **PTR Record**: Maps an IP address to a domain name (reverse DNS lookup).
