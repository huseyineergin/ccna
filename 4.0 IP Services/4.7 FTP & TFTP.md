# 4.7 FTP & TFTP
## TFTP (Trivial File Transfer Protocol)
TFTP is a simple protocol designed for basic file transfers, especially within local networks.
- It is called trivial because it is simpler than FTP and offers only basic features.
- TFTP does not use encryption or authentication.
- A TFTP server listens on **UDP port 69**.
- `#copy tftp: flash:` command copies a file from a TFTP server to the device's flash memory.
	- This command is interactive and prompts for the remote host's address or name, the source filename and the destination filename.
### TFTP Reliability
TFTP implements its own basic acknowledgments and retransmissions.
- Every TFTP data message is acknowledged.
- Timers are used, and if an expected message is not received in time, the waiting device will resend its previous message.
- TFTP uses **lock-step communication**, in which the client and server take turns sending messages and waiting for replies. Retransmissions occur as needed.

![TFTP Reliability](../Attachments/Images/TFTP%20Reliability.png)
### TFTP Connection
TFTP file transfers have three phases:
1. **Connection**: The TFTP client sends a request to the server, and the server responds, initiating the connection.
2. **Data Transfer**: The client and server exchange TFTP messages. One sends data, and the other sends acknowledgments.
3. **Connection Termination**: After the last data message has been sent, a final acknowledgment is sent to terminate the connection.
## FTP (File Transfer Protocol)
FTP is a standard protocol used to upload and download files between a client and a server over a network.
- FTP uses a username and password for authentication. However, it does not provide encryption.
	- `(config)#ip ftp username <username>` command specifies the username to use when authenticating with an FTP server.
	- `(config)#ip ftp password <password>` command specifies the password to use when authenticating with an FTP server.
- **FTPS (File Transfer Protocol Secure)**, upgrade to FTP, provides greater security.
- FTP is more complex than TFTP and supports not only file transfers but also other functions, such as navigating directories, creating and removing directories and listing files.
- FTP clients send **commands** to the server to perform various functions.
- FTP uses **TCP ports 20 and 21**.
- `#copy ftp: flash:` command copies a file from a FTP server to the device's flash memory.
	- This command is interactive and prompts for the remote host's address or name, the source filename and the destination filename.
### FTP Connections
FTP uses two separate connections:
- **Control Connection**: Sends commands and receives responses.
- **Data Connection**: Transfers files and directory information.
#### FTP Control Connection
An FTP control connection is the connection used by an FTP client and FTP server to exchange commands and responses.
- An **FTP control connection (TCP port 21)** is established and used to send FTP commands and receive replies.
- When files or other data need to be transferred, separate **FTP data connections (TCP port 20)** are established and terminated as needed.

![FTP Control Connection](../Attachments/Images/FTP%20Control%20Connection.png)
#### FTP Data Connection
An FTP data connection is the TCP connection used to transfer actual data between an FTP client and an FTP server.
- FTP has two main ways to establish its data connection, which are **active mode** and **passive mode**.
	- In active mode, the **server initiates** the data connection. This is the default method.
	- In passive mode, the **client initiates** the data connection. This is often necessary when the client is behind a firewall that could block incoming connections from the server.

## IOS File Systems
IOS file systems are the storage locations that Cisco devices use to store, access and manage files such as the IOS operating system images, configuration files and backups.
- File system of a Cisco device can be viewed with `#show file systems` command.
- There are different types of file systems:
	- **disk**: Storage devices such as flash memory.
		- The contents of flash memory can be viewed with `#show flash:` command.
	- **opaque**: Used for internal functions.
	- **nvram**: Internal NVRAM. the startup configuration is stored here.
	- **network**: Represents external file systems, such as external FTP/TFTP servers.
- `(config)#boot system <file-path>` command specifies the IOS image that the device should load during startup.
	- `(config)#boot system flash:c2900-universalk9-mz.SPA.155-3.M4a.bin`
- `#delete <file-path>` command deletes the specified file from the file system.
