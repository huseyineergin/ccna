# 2.4 Layer 2 Discovery Protocols
## Introduction
Layer 2 discovery protocols let network devices discover and identify their **directly connected neighbors**.
- The shared information includes **device identity, capabilities, interface information and other relevant details.**
- Because they share information about network devices, they can be considered a security risk and are therefore often disabled.
## CDP (Cisco Discovery Protocol)
CDP is a Cisco proprietary layer 2 discovery protocol that allows Cisco devices to discover information about other directly connected Cisco devices.
- It is enabled on Cisco devices by default.
	- `[no] cdp run` command enables/disables CDP globally.
	- `[no] cdp enable` command enables/disables CDP on a specific interface.
- CDP messages are periodically sent to multicast MAC address *0100.0CCC.CCCC*. CDPv2 messages are used by default.
	- `[no] cdp advertise-v2` command enables/disables CDPv2.
- When a device receives a CDP message, it processes and then discards the message. It **does not forward the message to other devices**.
- CDP messages are sent once **every 60 seconds** by default.
	- `cdp timer <seconds>` command configures the CDP timer.
- By default, the CDP hold time is **180 seconds**. If a message is not received from a neighbor within 180 seconds, the neighbor is removed from the CDP neighbor table.
	- `cdp holdtime <second>` command configures the CDP hold time.
- `show cdp` command displays basic information about CDP, such as timers and the CDP version.
- `show cdp traffic` command displays the number of CDP messages sent and received.
- `show cdp interface` command displays the interfaces on which CDP is enabled.
- `show cdp neighbors` command lists CDP neighbors and basic information about each neighbor.
- `show cdp neighbors detail` command lists CDP neighbors with detailed information.
- `show cdp entry <device-id>` command displays detailed information about the specified neighbor.
## LLDP (Link Layer Discovery Protocol)
LLDP is a layer 2 discovery protocol defined by **IEEE 802.1AB**.
- It is usually disabled on Cisco devices by default.
	- `[no] lldp run` command enables/disables LLDP globally.
	- `[no] lldp transmit` command enables/disables LLDP message transmission on a specific interface.
	- `[no ]lldp receive` command enables/disables LLDP message reception on a specific interface.
- A device can run CDP and LLDP at the same time.
- LLDP messages are periodically sent to multicast MAC address *0180.C200.000E*.
- When a device receives an LLDP message, it processes and then discards the message. It **does not forward the message to other devices**.
- LLDP messages are sent once **every 30 seconds** by default.
	- `lldp times <seconds>` command configures the LLDP timer.
- By default, the LLDP hold time is **120 seconds**.
	- `lldp holdtime <seconds>` command configures the LLDP hold time.
- LLDP has an additional timer called the **reinitialization delay**. When LLDP is enabled, this timer delays the actual initialization of LLDP. It is **2 seconds** by default.
	- `lldp reinit <seconds>` command configures the LLDP reinitialization delay.
- `show lldp` command displays basic information about LLDP, such as timers and the status.
- `show lldp traffic` command displays the number of LLDP messages sent and received.
- `show lldp interface` command displays the interfaces on which LLDP is enabled.
- `show lldp neighbors` command lists LLDP neighbors and basic information about each neighbor.
- `show lldp neighbors detail` command lists LLDP neighbors with detailed information.
- `show lldp entry <device-id>` command displays detailed information about the specified neighbor.
